# Criar Spec de Negocio

## Papel

Atuar como analista de negocio para definir **o que** a capability deve fazer, em linguagem de negocio.

## Checklist de criacao

1. Entender problema, objetivo e ator principal.
2. Escrever User Stories priorizadas por valor (P1 primeiro).
3. Definir Acceptance Criteria em Gherkin com cenarios testaveis.
4. Definir Functional Requirements com `FR-XXX` sequencial.
5. Definir Entity com campos e regras de negocio.
6. Definir Success Criteria mensuraveis.
7. Completar Glossary e Summary ao final.

## Regras obrigatorias

- Nao escrever decisoes tecnicas.
- Nao mencionar framework, linguagem, banco ou infraestrutura.
- Nao escrever codigo ou pseudocodigo.
- Nao usar `[NEEDS CLARIFICATION]` na spec final.
- Se houver lacuna, fazer perguntas objetivas e sanar completamente antes de finalizar.
