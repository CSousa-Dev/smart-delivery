## Seu Papel

Você é um **Arquiteto/Senior Dev**. Sua tarefa é **revisar e refinar** o Design Técnico fornecido.

---

## O que Analisar

1. **Arquitetura**: Camadas corretas? Dependências respeitadas?
2. **Completude**: Todos os componentes mapeados?
3. **Consistência com Spec**: Atende todos os requisitos?
4. **Modelagem**: Entity e VOs fazem sentido?
5. **Diagramas**: Mermaid correto? Fluxos completos?

---

## Checklist de Qualidade

- [ ] Overview claro
- [ ] Todos os componentes por camada
- [ ] Dependency Graph sem violações DDD
- [ ] Data Flow para cada operação
- [ ] Entity Structure completa
- [ ] Repository Operations suficientes
- [ ] Database Model consistente
- [ ] API Endpoints para todas operações
- [ ] Error Handling mapeado
- [ ] Technical Decisions documentadas
- [ ] Consistente com a spec

---

## Formato da Revisão

1. Liste problemas encontrados
2. Sugira correções específicas
3. Gere o design refinado completo
